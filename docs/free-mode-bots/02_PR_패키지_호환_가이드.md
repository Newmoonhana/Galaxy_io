## 서버 운영 (이 PC 에서 서버를 엶)

- 게임 서버: UDP/TCP 7979 (PC 클라이언트 UDP, 웹 ws TCP)
- 기존 http 웹: 8000 (`serve_web.py`)
- https 웹, wss: Caddy (`tools/caddy/Caddyfile`) - 443(웹 파일), 7980(wss -> 127.0.0.1:7979), 관리 API 127.0.0.1:20190
- 공유기 포트포워딩: TCP 80, 443, 7979, 7980, 8000 / UDP 7979 (+ UDP 443 선택)
- https 웹 클라이언트는 페이지가 https 면 자동으로 `wss://같은호스트:7980` 으로 접속(`WebSecureConnection`). http 페이지와 PC 클라이언트는 그대로 7979.

## 설정 (server_config.json)

항목이 없으면 코드 기본값을 씁니다. 원래대로 돌리고 싶을 때:

```json
{
  "Bots": { "Enabled": false },
  "Enemies": { "CapBase": 15, "CapPerPlayer": 30, "RadarCap": 30, "SpawnPerRadar": 6, "SpawnInterval": 1.5, "HealthScale": 1.0, "DamageScale": 1.0 },
  "Spectator": { "Enabled": false }
}
```

봇 세력 구성, 피해 배율, 리스폰 시간 등 전체 항목은 `Scripts/DOTS/Bots/BotSettings.cs` 주석에 있습니다.
