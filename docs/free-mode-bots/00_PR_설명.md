## 2. 필요한 빌드 4종 (모두 같은 커밋)

| 빌드 | 방법 | 비고 |
|---|---|---|
| **데디 서버** | 메뉴 `GalaxyIO/Build/Bot Server (Dedicated)` (또는 기존 서버 빌드) | 실행 폴더의 `server_config.json` 을 읽음. 자유 모드면 봇 자동 생성. 포트 UDP/TCP 7979 |
| **Unity 클라이언트(Windows)** | 기존 클라이언트 빌드 방식 | 에디터를 새로 켠 뒤 빌드 권장 |
| **관찰자 클라이언트** | 메뉴 `GalaxyIO/Build/Spectator Client (Windows)` | 일반 클라이언트와 같은 빌드에 실행 인자만 다름: `-spectator -spectate-address <서버주소> [-spectate-name @spectator]` |
| **웹(WebGL) + 웹 서버** | 기존 `GalaxyIO/Build/Web Release (Multithreaded)` | 템플릿 `WebGLTemplates/GalaxyIO/index.html` 에 닉네임 화면, 터치 버튼 포함. 웹 서버는 COOP/COEP 헤더 필요(기존 serve_web.py 와 같음) |

### https / wss (모바일, 일반 브라우저 접속용)
- https 페이지에서는 브라우저가 `ws://` 를 막으므로, 페이지가 https 면 클라이언트가 자동으로 **`wss://같은호스트:7980`** 으로 접속(`WebSecureConnection`).
- 서버 PC 앞에 TLS 프록시가 필요: 443(웹 파일) + 7980(wss → 127.0.0.1:7979). 작성자는 Caddy 사용(인증서 자동). http 페이지와 PC 클라이언트는 그대로 7979.
- 포트포워딩: TCP 80, 443, 7979, 7980 / UDP 7979.

## 4. 중요 / 주의

1. **자유 모드 외 모드**: 봇 디렉터는 `GameMode.Free` 이고 팀 모드 싱글톤이 없을 때만 켜짐. 피해 배율, 플레이어 강화도 봇 디렉터가 켜졌을 때만. 단 몹 조정(`Enemies`)은 모든 데디 서버에 적용 → 원치 않으면 server_config 에 `"Enemies": {"HealthScale": 1, "DamageScale": 1, "CapPerPlayer": 30, "RadarCap": 30, "SpawnPerRadar": 6}`.
2. **봇 끄기**: server_config `"Bots": {"Enabled": false}`. 관찰자 끄기: `"Spectator": {"Enabled": false}`.
3. **관찰자 복제 반경 100000**: 관찰자는 모든 함대를 받음(트래픽 큼). 필요하면 `Spectator.Radius` 로 줄임.
4. **사운드**: 새 연출 소리는 기존 PF_Core 그룹만 사용(`UI_Press`, `ThorExplosion`). 엔진음, 재장전 전용음은 그룹이 없어 넣지 않음 → 넣으려면 PF_Core 에 그룹 추가 후 인스펙터 문자열만 바꾸면 됨.
5. **히트 스톱 없음**: 네트워크 예측과 어긋나서 넣지 않음(흔들림으로 대체).
6. **관찰자 패널**: 기능은 완성(플레이어, NPC 함대, 함선 고정, 자유 시점, 확대, 나이트호크 최대 강화 레이더), 패널 그림은 Unity IMGUI → 원작 UI 스타일로 바꾸는 작업은 남음.
7. **모바일 기기별 화면(플립, 폴드, 태블릿)** 은 실기기/에뮬레이션 확인 전. 터치 중 HUD 이동은 `MobileCanvasFitter` 가 실행 시점에 함(프리팹 수정 없음).
